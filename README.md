# Neon Strike FPS

A small Python desktop FPS prototype built with Ursina.

## Requirements

- Python 3.10+
- pip

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install ursina
```

## Run

```bash
python main.py
```

## Controls

- W, A, S, D: move
- Mouse: look around
- Left click: shoot
- Space: jump
- R: restart after death

## Goal

Survive waves of enemies, defeat them, and keep your score climbing.
