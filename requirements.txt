# Neon Siege

A desktop 3D shooter built in Python with Ursina.

This project is not a browser game and is meant to run as a standalone desktop application on GitHub.

## Requirements

- Python 3.10+
- pip

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Controls

- W A S D: move
- Mouse: aim
- Left click: shoot
- Shift: sprint

## Goal

Survive the swarm, keep firing, and reach 200 points.
